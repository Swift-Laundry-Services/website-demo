# Swift Laundry Services — demo for client review

> Demo site built from the modernized PDF site (`website-modern-pdf`) plus the 2026 rebuild design package
> (route map, mockups and written spec). Live at **https://swift-laundry-services.github.io/website-demo/**.
> It is marked `noindex` and blocked in `robots.txt` because it is a review copy.

## What's here
Static HTML/CSS/vanilla JS, no build step needed to deploy. Pages are generated by `_build/build.py`
(shared header, menu, tab bar and footer), so edit the generator and run `python3 _build/build.py`.

| Route | Page |
|---|---|
| `index.html` | Home |
| `services.html` | Services & Pricing |
| `pickup.html` | Schedule a Pickup (3-step form) → `request-received.html` |
| `about.html` | About & laundry preferences |
| `service-area.html` | Service Area & Contact (ZIP checker, map, contact form) |
| `how-it-works.html` | How It Works |
| `faq.html` | FAQs grouped by category, with search |
| `laundry-care.html` | Laundry Care Information |
| `privacy.html`, `service-terms.html` | Text-page drafts (owner must supply final wording) |
| `404.html` | Not-found page |
| `order.html`, `contact.html`, `why-choose-us.html`, `login.html` | Redirects to the new routes |

## Owner settings
`assets/js/site-config.js`: prices, extra-weight rate, **`zips`** (served ZIP codes; empty = manual check), social links,
testimonials, and form delivery (`forms.endpoint` for a real form service, otherwise the mailto fallback).

Anything that still needs the owner's confirmation shows a small "To be confirmed" badge, and the footer carries a demo note.

## Deploy
GitHub Pages via `.github/workflows/pages.yml` on push to `main`. `_build/` is excluded from the published site.

## Pickup flow & time slots
The Schedule a Pickup page has four steps: details, choose your load (with quantities), pickup date and 1-hour time slot, then a review page with the estimated total. Load prices come from `pricing.washFold` and the time slots from `pickup` in `assets/js/site-config.js`.
